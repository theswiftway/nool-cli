Agentic Change Control for AI Coding Agents

Nool is the control plane between an AI coding agent's intent and the codebase it is allowed to change. Compute semantic blast radius, enforce declared scope, and keep Git workflows intact.

TRADITIONAL AGENT (ENTROPY)
$ git checkout refactor-auth
$ agent "Continue the refactor..."
[ERROR] Context lost. Unable to determine intent of previous session mutations.
Searching codebase for clues... (5m elapsed)
NOOL-POWERED AGENT (GOVERNED)
$ git checkout refactor-auth
$ nool discover features
$ nool announce intent --intent "Continue auth refactor"
[SUCCESS] Declared scope recorded. Collision scan passed.
[SUCCESS] Feature boundaries mapped. Policy gates ready.
$ agent "Continue the refactor..."
"Ready. Resuming token validation logic in src/auth/tokens.rs..."

The AI Change-Control Problem

Fast agents can change more than they promised. Nool makes scope, impact, and causal justification inspectable before the repository accepts the result.

Scope Drift

Agents can refactor beyond their declared intent. Nool compares declared scope against computed semantic blast radius.

Unreviewable Impact

Byte diffs do not explain semantic reach. Nool surfaces transitive impact across related files, tests, and interfaces.

Ungoverned Autonomy

Productive agents still need policy gates, causal evidence, and durable findings. Nool provides the governance runtime.

How Nool Governs AI Code Change

Nool provides agentic change control without replacing Git or breaking existing repository workflows.

Semantic Impact Envelope

Compare declared intent against computed semantic blast radius and require reconciliation when implementation exceeds scope.

Durable Causal Ledger

Persist intent, impact, findings, decisions, and justifications as repository state rather than fragile session memory.

Multi-Agent Coordination

Coordinate parallel agents through intent announcements, contention detection, shared semantic state, and policy-gated transitions.
